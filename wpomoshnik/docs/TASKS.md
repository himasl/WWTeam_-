# Задачи на двоих

Разделение: Никита ведёт ядро, API и интерфейс, коллега ведёт модель, поиск и базу знаний. Продуктовая работа поделена пополам. У каждого по 7 задач.

Пометка «черновик есть» значит, что код уже лежит в репозитории и его нужно проверить и довести.

## Никита: ядро, API, интерфейс

К демо 11 октября:

1. Залить черновик в репозиторий, поднять по README, выложить демо на стенд. Черновик есть.
2. Довести API: `/api/ask`, `/api/escalate`, `/api/stats`, обработка ошибок. Черновик есть.
3. Экран встречи: проверить на планшете, проверить голосовой ввод в Chrome. Черновик есть, на планшете не проверен.
4. Записать видео-демо основного сценария и вставить ссылку в форму.

К сдаче спринта 1 ноября:

5. Экран аналитики для руководителя: фильтр по периоду, выгрузка пробелов. Черновик есть.
6. Режим новичка и чек-листы: дописать словарь терминов, чек-листы под остальные продукты.
7. Интервью с 3-4 выездными менеджерами, записать, как они ищут ответ при клиенте.

## Коллега: модель, поиск, база знаний

К демо 11 октября:

1. Подключить Ollama и проверить ответы модели: промпт, разбор JSON, отказ «нет ответа». Код есть, с настоящей моделью не проверен.
2. Сверить цифры в `kb/` с официальными тарифами банка, исправить расхождения.
3. Составить 50 тестовых вопросов с правильными ответами, из них 10 без ответа в базе.
4. Улучшить поиск: добавить векторный поиск к BM25, чтобы проходили длинные разговорные вопросы.

К сдаче спринта 1 ноября:

5. Замерить качество на тестовых вопросах: доля верных ответов, доля верных отказов. Цифры идут в презентацию.
6. Проверить работу на российской или локальной модели, это требование трека.
7. Интервью с 3-4 выездными менеджерами, оценка охвата и презентация.
